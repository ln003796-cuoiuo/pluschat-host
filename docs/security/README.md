# Безопасность

- Только HTTPS/WSS.
- Секреты и ключи вне Git.
- Пароли — безопасный password hashing API.
- Сессии/токены имеют срок действия и отзыв.
- Rate limiting для входа, API и загрузок.
- Серверная проверка каждого права.
- Параметризованные запросы/ORM.
- Валидация входных данных, XSS/CSRF защита где применимо.
- Файлы проверяются и хранятся вне public web-root в зашифрованном виде.
- Временные ссылки только после проверки доступа.
- Аудит важных действий и событий безопасности.
- Пользовательские ошибки не раскрывают stack trace, SQL, пути сервера или секреты.
- E2EE не объявляется реализованным до фактической реализации и аудита протокола.
