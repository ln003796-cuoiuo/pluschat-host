# PlusChat Host

Серверная часть PlusChat. Основной стек: PHP, PostgreSQL/MySQL, Redis, WebSocket и защищённое файловое хранилище.

`прото.плюсчат.рф` — защищённая точка связи приложения с серверной инфраструктурой.

## Модули
Авторизация, пользователи и устройства, ЛС, сообщения, группы, каналы, темы, файлы, уведомления, поиск, звонки, безопасность, аудит, админ-панель, ошибки, мониторинг и резервное копирование.

## Безопасность
HTTPS/WSS, безопасное хеширование паролей, отзыв сессий, rate limiting, серверная проверка прав, защита от SQL injection/XSS/CSRF, валидация файлов, шифрованное хранение файлов, временные ссылки и аудит. Секреты не хранятся в Git.

API: `/api/v1/`.
